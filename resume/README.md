## 4. Updating & Maintenance Rules

To keep the resume credible, effective, and ATS-compliant, follow these strict rules:

1. **Truthful Technical Stack:** Only list technologies that you actively work with and can comfortably discuss in technical interviews. Never inflate the stack with tools you have not used.
2. **Real Project Work:** Highlight technical architecture, specific problem-solving steps, and tangible functionality. Never invent metrics, user statistics, revenue numbers, or enterprise partnerships.
3. **1-Page Limit:** Keep the resume strictly to **one page**. Maintain clean margins (0.5–0.75 in), concise bullet points (2–3 per project), and standard font sizing (10–11pt body, 12–14pt headings).
4. **ATS Friendliness:**
   - Avoid tables, text boxes, graphics, photos, and multi-column layouts that confuse Applicant Tracking Systems.
   - Use standard section headers: `PROFESSIONAL SUMMARY`, `EDUCATION`, `TECHNICAL SKILLS`, `PROJECTS`, `COMPETITIVE PROGRAMMING & OPEN SOURCE`.
   - Use standard bullet points and consistent date formats (`Expected Graduation: 2029`).
5. **Updating Experience:** When you land internships or professional client work, create a dedicated `EXPERIENCE` section directly below `EDUCATION`, detailing your role, organization, duration, and key technical deliverables.
